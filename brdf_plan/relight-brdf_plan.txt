================================================================================
 BRDF Explorer — Detailed Development Plan
================================================================================

GOAL
----
Build a standalone Qt desktop app that makes every step of the BRDF fitting
pipeline visible and interactively tunable, so we can quickly spot where the
heuristics fail and why.

It lives in a new top-level directory:  brdflab/
It reuses code from relightlab/ and src/ without modification.

2.  DATA FLOW
────────────────────────────────────────────────────────────────────────────────

  [Load folder / .lp]
       │
       ▼
  ImageSet (full resolution, reads lights from .lp)
       │
  User clicks pixel → picks (cx, cy) in image coordinates
       │   User sets patch_size (odd, 5–101)
       ▼
  Extract patch: PixelArray  [patch_size² pixels × K lights]
  using ImageSet::setCrop(Crop(cx-r, cy-r, patch_size, patch_size))
       │
       ▼
  BrdfExplorer::compute(patch, lights, ExplorerParams)
       │  for every pixel in patch:
       │    1. init_normal()            → InitNormalResult
       │    2. optimize_brdf_pixel()   → BrdfFitResult
       │    3. per-light eval_gltf()   → render buffer
       │
       ▼
  Emit signals → update all panels

────────────────────────────────────────────────────────────────────────────────
3.  EXPLORER PARAMETERS  (ExplorerParams struct in brdfexplorer.h)
────────────────────────────────────────────────────────────────────────────────

All parameters are exposed in ParamsPanel as labelled spinboxes / sliders /
checkboxes with immediate recompute on change.

  patch_size          int        5–101 step 2         default 21
  light_intensity     float      0.1–20.0              default 4.0
  metallic_hf_thresh  float      0.0–1.0               default 0.15
    (highlight_fraction < this  → metallic)
  metallic_pr_thresh  float      1.0–20.0              default 3.0
    (peak_ratio > this          → metallic)
  shadow_zscore_scale float      0.5–10.0              default 3.0
    (shadow_probability = clamp(deficit / shadow_sigma / scale, 0, 1))
  optimize_normal     bool       checkbox              default true
  optimize_albedo     bool       checkbox              default true
  initial_roughness   float      0.0–1.0               default 0.3
  initial_metallic    float      0.0–1.0               default uses heuristic
  use_gltf_brdf       bool       checkbox              default true
    (false → eval_ggx)

When any parameter changes → BrdfExplorer::recompute() is called.
A QFutureWatcher runs the computation in a background thread (QtConcurrent::run).
A progress bar in the status bar shows activity.

    for the patch bounding box, QGraphicsLineItem cross-hair — all cosmetic pen.

5.  RESULTS PANEL  (resultspanel.h/cpp)
────────────────────────────────────────────────────────────────────────────────

A QTabWidget with the following tabs:

5a.  MAPS tab
     ─────────
     6 fixed-size QLabel image tiles arranged in a 2×3 grid:

     Row 1:  [Albedo RGB]      [Final Normal]    [Roughness]
     Row 2:  [Metallic mask]   [Init Normal]     [Init Metal mask]

     Each tile is 256×256 px (upscaled from patch with nearest-neighbour).
     Below each tile: its name + value range tooltip on hover.

     Map encoding (same as BrdfTask saveMap):
       albedo:       linear RGB → display (sRGB conversion via lcms2)
       normal:       xyz → (x*0.5+0.5, y*0.5+0.5, z*0.5+0.5)
       roughness:    grey [0–1]
       metallic:     grey [0–1]
       init_normal:  xyz encoding
       init_metallic: binary white/black

5b.  DIAGNOSTICS tab
     ─────────────────
     3 tiles:
       [Highlight fraction]   [Peak ratio]   [Lambertian variance]
     Same scale / upscale convention as Maps tab.

5c.  PER-LIGHT RENDER tab
     ──────────────────────
     Left half:  the original cropped patch for the currently selected light.
     Right half: BRDF re-render of that patch using the fitted maps + that light.
     Both are upscaled 256-px squares.
     A slider / spinbox below selects the active light index.
     Shows RMSE (root mean squared error per pixel) for the selected light.

5d.  REFLECTANCE PLOT tab
     ──────────────────────
     Embeds the plot_reflectance() output (reuse existing function, render into
     QImage in memory instead of saving to disk) for the centre pixel of the
     patch, shown as a 640×400 QLabel.
     Recomputed whenever the patch or parameters change.

5e.  RUSINKIEWICZ tab
     ──────────────────
     Embeds write_rusinkiewicz_html() output in a QWebEngineView (or, if
     QtWebEngine is unavailable, offer a "Save HTML" button that writes to a
     temp file and opens the browser).

────────────────────────────────────────────────────────────────────────────────
6.  LIGHT DIRECTION WIDGET  (lightdirwidget.h/cpp)
────────────────────────────────────────────────────────────────────────────────

A small square QWidget (200×200) that draws a hemisphere:
  • Grey filled circle = upper hemisphere projection.
  • Red dot = current light direction (L).
  • Blue dot = current view direction (V), default (0,0,1).
  • Drag red or blue dot with mouse to set L / V.
  • Emit lightChanged(Eigen::Vector3f) / viewChanged(Eigen::Vector3f).

Connected to:
  • DatasetPanel: moving L snap-selects the nearest light index from .lp.
  • ResultsPanel PER-LIGHT RENDER: re-renders patch with chosen L at runtime
    (does not refit — only re-evaluates eval_gltf with fitted params).

────────────────────────────────────────────────────────────────────────────────
7.  SURFACE VIEW  (surfaceview.h/cpp)
────────────────────────────────────────────────────────────────────────────────

A QOpenGLWidget that renders the patch as a height-field mesh:
  • Vertices: grid of patch_size × patch_size points.
  • Z coordinate: derived from the fitted normal map via naive integration
    (sum of slopes, good enough for small patches).
  • Vertex colours: albedo map.
  • Shading: eval_gltf called in a GLSL fragment shader using fitted
    roughness and metallic uniforms, plus a movable point light (same L as
    LightDirWidget).
  • Camera: orbit with left-drag; zoom with scroll-wheel.

Minimum viable version (MVP):
  Render a flat z=0 grid with albedo colours and Phong shading — ship the
  proper normal-integration height field in a later iteration.

9.  BRDFEXPLORER CORE CLASS  (brdfexplorer.h/cpp)
────────────────────────────────────────────────────────────────────────────────

class BrdfExplorer : public QObject {
  Q_OBJECT
public:
  void loadFolder(const QString& path);   // wraps ImageSet::initFromFolder
  void setCenter(int cx, int cy);
  void setParams(const ExplorerParams& p);
  void recompute();                       // async via QtConcurrent

signals:
  void computationStarted();
  void computationFinished(BrdfExplorerResult);

private:
  ImageSet imageset;
  int cx, cy;
  ExplorerParams params;
};

struct BrdfExplorerResult {
  int patch_size;
  // Per-pixel arrays (patch_size × patch_size, row-major):
  std::vector<Eigen::Vector3f> normals_final;
  std::vector<Eigen::Vector3f> albedo;
  std::vector<float>           roughness;
  std::vector<float>           metallic;
  std::vector<Eigen::Vector3f> normals_init;
  std::vector<float>           metallic_init;     // binary
  std::vector<float>           highlight_fraction;
  std::vector<float>           peak_ratio;
  std::vector<float>           lambertian_variance;
  // Per-pixel × per-light shadow masks:
  std::vector<std::vector<float>> shadow_prob;    // [pixel][light]
  // Per-light render buffers  (each is patch_size² × RGB float):
  std::vector<std::vector<Eigen::Vector3f>> render;
  // Centre-pixel Ceres result (for plots):
  brdf::BrdfFitResult centre_fit;
};

12. KEY DESIGN DECISIONS & NOTES
────────────────────────────────────────────────────────────────────────────────

• Do NOT modify any file under src/ or relightlab/ — all reuse is via shared
  compilation units in brdflab.pro.

• init_normal() currently has hard-coded thresholds (0.15 / 3.0 / 3.0).
  Expose these from ExplorerParams and pass them into init_normals.cpp by
  adding an optional ExplorerParams* argument that overrides the defaults.
  If nullptr, the function behaves exactly as before (no behaviour change for
  existing callers).

• For the reflectance plot, refactor plot_reflectance() in brdftask.cpp to
  return a QImage instead of saving to disk.  Add a one-line wrapper that
  saves it (keeps existing CLI behaviour intact).

• The Rusinkiewicz HTML is self-contained — write to QTemporaryFile and load
  into QWebEngineView::setUrl(QUrl::fromLocalFile(tmpPath)).  Fallback:
  QDesktopServices::openUrl.

• Shadow masks: InitNormalResult::shadow_probability is per-light.
  In the per-light render tab, overlay the shadow mask as a red tint on the
  render image for the selected light.

• Thread safety: BrdfExplorer::recompute() creates a private copy of
  ExplorerParams + PixelArray before launching the background job.  UI is
  never blocked.  If a new recompute is triggered while one is running,
  cancel the old one (use QFuture::cancel + QFutureWatcher).
